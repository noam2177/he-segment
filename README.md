# he-segment

פיצול תחיליות עבריות מהגזע. שלוש מערכות על אותו זהב: בייסליין, לקסיקון שנבנה רק מ-train, ומודל תווים שאומן רק על train.

גרסה 1 נעולה ב-`fixtures/v1_gold.json`. המבחן ב-`fixtures/frozen_test.json` לא זז.

`normalize_text` מוריד תחיליות ממשפט. על 74 מילות המבחן הנעול המודל צודק ב-64, והלקסיקון ב-36, והבייסליין ב-36. הטסט בודק שהשלושה האלה נשארים. חמש מילים שהלקסיקון פותר והמודל משאיר שלמות רשומות ב-`NOTE.md`. שורות מועמדות שהורידו את 64 ל-53 לא נכנסו לאימון.

```text
python -m unittest discover -s tests -q
python -m he_segment.report
```

השלבים, מהסוף אחורה, ב-`PLAN.md`.
